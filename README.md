# Aplicación de trazabilidad y gestión operativa

Este repositorio reúne componentes de software desarrollados durante una experiencia de práctica profesional, incluyendo servicios backend, APIs y una aplicación web para consultar y gestionar información operacional.

## Componentes

- Servicios backend desarrollados con Node.js y TypeScript.
- APIs REST para consulta y procesamiento de información.
- Aplicación web desarrollada con Vue.
- Integración con bases de datos relacionales y NoSQL.
- Autenticación e integración con un proveedor de identidad.
- Validación de entradas, controles de acceso y medidas de seguridad para APIs.

## Tecnologías

Node.js, TypeScript, JavaScript, Express, Vue, MySQL, MongoDB y Keycloak.

## Configuración

Los archivos `.env.example` contienen únicamente los nombres de las variables requeridas. Para ejecutar los servicios, crea un archivo local `.env` o configura las variables en el entorno de despliegue.

No incluyas credenciales, tokens, direcciones de servidores, nombres de usuarios, endpoints internos, identificadores de aplicaciones ni datos operacionales reales en este repositorio.

## Nota de seguridad

Este código se publica con fines demostrativos. Las configuraciones de infraestructura y los datos propios de la organización han sido excluidos o sustituidos por variables de entorno. No debe conectarse a sistemas productivos desde entornos públicos.
